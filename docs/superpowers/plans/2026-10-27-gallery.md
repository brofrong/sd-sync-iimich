# Галерея — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вкладка «Галерея»: JPEG с выбранной вставленной карты по дням, статус на каждой фотке, просмотр крупно со стрелками.

**Architecture:** новый пакет `internal/gallery` (список снимков карты со статусами, миниатюры, HTTP-обработчик картинок по id) подключается к серверу ресурсов Wails через `AssetOptions.Middleware`; `gui.Service` отдаёт окну список (`Gallery()`) и переключает полноэкранный режим. Uploader сообщает файлы «в работе» в прогрессе (`InFlight`), окно накладывает их поверх статусов. Фронтенд: секция `Gallery.svelte` и слой `PhotoViewer.svelte`.

**Tech Stack:** Go 1.26, Wails `v3.0.0-beta.34`, `golang.org/x/image/draw` (уже в go.sum, станет прямой зависимостью), Svelte 5.

**Spec:** `docs/superpowers/specs/2026-10-27-gallery-design.md`

## Global Constraints

- Показываются только `.jpg`/`.jpeg` (регистр не важен), найденные `scanner.ScanVolume` с текущим конфигом; остальные найденные файлы — только числом (`other`).
- Карта — только `app.MountedTarget()` (выбранная и вставленная). Ничего не пишется на карту.
- Картинки отдаются **только по id** из последнего списка; путь из URL никогда не превращается в путь к файлу. Неизвестный id или чужое поколение — 404.
- Время съёмки — `mtime` файла; день — в местном часовом поясе (группирует фронтенд, `formatDay` из `lib/i18n.ts`).
- Статусы Go: `"in_immich"` (курсор карты покрывает файл или есть `uploaded_at`), `"failed"` (в `sync_run_failures` последней завершённой синхронизации этой карты), иначе `"waiting"`. Фронтенд показывает `"uploading"` для путей из `$status.progress.inFlight`, если Go не сказал `"in_immich"`.
- Миниатюры: EXIF-миниатюра (IFD1), повёрнутая по Orientation из IFD0; без неё — уменьшение до 400 px по длинной стороне, JPEG качество 80. Кэш в памяти, сбрасывается при новом списке другой карты. Одновременных чтений файлов галереей — не больше 3.
- Окно запрашивает `Gallery()` не чаще раза в 2 с во время синхронизации; повторный обход карты — только при смене карты или если кэш старше 60 с.
- Все строки UI — на 8 языках (`frontend/locales/*.json`), тест `internal/i18n` проходит.
- **Безопасность разработки:** не запускать собранное приложение, не трогать `/Volumes`, `~/.config/sd-sync-immich`, LaunchAgent; тесты — временные каталоги и `testenv.Home`; JPEG для тестов генерируются в тесте.
- Проверка перед коммитом: `go vet ./... && go test ./...`; Windows-компиляция `GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go vet ./internal/gallery/ ./internal/uploader/ ./internal/state/`; фронтенд — `cd frontend && npm run check && npm run build`. После изменений Go-типов окна — перегенерировать привязки: `go run github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.34 generate bindings -silent -clean=true -d frontend/bindings -ts ./cmd/sd-sync-immich`.

## Review Focus

1. Карту вынули, пока открыт просмотр или грузятся миниатюры → запросы картинок отвечают 404/ошибкой без паники, вкладка показывает «Вставьте карту». Тест: Task 4 `TestHandlerAfterCardRemoved`.
2. Вертикальное фото (Orientation 6) → миниатюра в сетке стоит вертикально. Тест: Task 3 `TestThumbnailRotatesByOrientation`.
3. JPEG без EXIF или с обрезанным/битым APP1 → миниатюра из запасного пути, не ошибка. Тест: Task 3 `TestThumbnailWithoutExif`, `TestThumbnailBrokenExif`.
4. URL вида `/gallery/thumb/<gen>/../../etc/passwd` или чужой id → 404. Тест: Task 4 `TestHandlerRejectsUnknownIDs`.
5. 2000+ фото → вкладка открывается без подвисания, прокрутка плавная. Проверка: Task 6 в браузере на моке с 2000 фото.

### Task 3: Миниатюры (gallery/thumbnail)

**Files:** Create `internal/gallery/thumbnail.go`, `internal/gallery/thumbnail_test.go`; `go.mod` (x/image → прямая).

**Interfaces — Produces:**
- `func Thumbnail(path string) ([]byte, error)` — JPEG миниатюры. Читает первые 128 КБ; ищет APP1 `Exif\0\0`, TIFF (II/MM), IFD0 → тег 0x0112 Orientation (1–8, по умолчанию 1), IFD1 → 0x0201/0x0202 (offset/length миниатюры относительно TIFF-заголовка). Если миниатюра есть и декодируется — повернуть/отразить по Orientation (если ≠1) и закодировать заново; при Orientation 1 отдать байты как есть. Иначе — декодировать весь файл, уменьшить до 400 px по длинной стороне (`draw.ApproxBiLinear` или `CatmullRom`), повернуть по Orientation, JPEG качество 80. Разбор EXIF своим кодом (~100 строк), без новых библиотек.
- `func orient(img image.Image, o int) image.Image` — 8 вариантов EXIF.

- [ ] Тесты с JPEG, собранными в тесте (`image/jpeg` + вручную склеенный APP1 с IFD0 Orientation и IFD1-миниатюрой): `TestThumbnailUsesExifThumbnail` (основной снимок 1200×800 синий, встроенная 160×106 красная → результат красный, размер 160×106); `TestThumbnailRotatesByOrientation` (Orientation 6, встроенная 160×106 → результат 106×160); `TestThumbnailWithoutExif` (2000×1000 без APP1 → 400×200); `TestThumbnailBrokenExif` (APP1 с обрезанным IFD/смещением за пределы → запасной путь, без ошибки); `TestThumbnailBigEndian` (TIFF `MM`).
- [ ] Реализация, тесты зелёные, коммит `feat(gallery): thumbnails from the EXIF preview`.

### Task 4: Список снимков и обработчик картинок (gallery)

**Files:** Create `internal/gallery/gallery.go`, `internal/gallery/handler.go`, тесты `gallery_test.go`, `handler_test.go`.

**Interfaces — Consumes:** Task 1 (`Covers`, `UploadedPaths`, `LastFinishedRunFor`, `RunFailures`), Task 3 (`Thumbnail`).
**Produces:**
```go
type Photo struct {
    Path    string    `json:"path"`    // относительный, как в Progress.InFlight
    Name    string    `json:"name"`
    TakenAt time.Time `json:"takenAt"`
    Size    int64     `json:"size"`
    Status  string    `json:"status"`  // "in_immich" | "failed" | "waiting"
    Thumb   string    `json:"thumb"`   // "/gallery/thumb/<gen>/<i>"
    Src     string    `json:"src"`     // "/gallery/photo/<gen>/<i>"
}
type List struct {
    CardUUID string  `json:"cardUuid"`
    CardName string  `json:"cardName"`
    Photos   []Photo `json:"photos"` // новые сверху: TakenAt убыв., затем Path убыв.
    Other    int     `json:"other"`  // найдено, но не JPEG
}
type Gallery struct { /* cfg *config.Store, st *state.DB, mu, кэш скана, поколение, кэш миниатюр, семафор на 3 */ }
func New(cfg *config.Store, st *state.DB) *Gallery
func (g *Gallery) List(vol volume.Info) (List, error)   // скан кэшируется по (UUID, MountPoint) на 60 с; статусы считаются заново каждый раз
func (g *Gallery) Clear()                                // забыть скан и миниатюры (карту вынули)
func (g *Gallery) Middleware(next http.Handler) http.Handler // /gallery/thumb|photo/<gen>/<i>, остальное → next
```
Поколение (`gen`) растёт при каждом новом скане; id — индекс в списке этого поколения. `/photo` — `http.ServeContent` (имя, mtime, файл открыт на время ответа); `/thumb` — `Thumbnail`, кэш по индексу, `Content-Type: image/jpeg`, `Cache-Control: private, max-age=3600`. Ошибка чтения файла → 404 (карта вынута), лог `logx.Warn` один раз на поколение.

- [ ] Тесты (`t.TempDir()` как карта, `config.Default()` в `config.Store` во временном `testenv.Home`, временная база): `TestListOnlyJPEGNewestFirst` (3 JPG разных mtime + 1 ARW + 1 MP4 → 3 фото по убыванию, `Other == 2`); `TestListStatuses` (курсор покрывает старый файл → `in_immich`; `MarkUploaded` новее курсора → `in_immich`; путь в failures последней завершённой синхронизации → `failed`; остальное → `waiting`); `TestListRescansAfterCardChange`; `TestHandlerServesKnownIDs` (thumb → 200 image/jpeg; photo → 200 и байты файла; Range работает); `TestHandlerRejectsUnknownIDs` (индекс вне списка, старое поколение, `../`, нечисловой id → 404; `/other` уходит в `next`); `TestHandlerAfterCardRemoved` (файл удалён после `List` → 404, без паники).
- [ ] Реализация, `go test ./internal/gallery/` зелёный, коммит `feat(gallery): list a card's photos and serve them by id`.
