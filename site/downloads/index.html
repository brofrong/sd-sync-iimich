The latest version. Needs an Immich v3 server.

macOS Your system

macOS 13 or later · Apple Silicon and Intel · SD-Sync-Immich.dmg
Download .dmg
  1. Open the .dmg and drag SD Sync Immich onto the Applications folder.
  2. The app is not signed with an Apple Developer ID, so macOS blocks the first launch: open System Settings → Privacy & Security and click Open Anyway next to SD Sync Immich.

Or with Homebrew, then the same step 2:

brew tap brofrong/tap
brew trust --cask brofrong/tap/sd-sync-immich
brew install --cask sd-sync-immich

Windows beta Your system

Windows 10 or 11 · x64 · SD-Sync-Immich-Setup-x64.exe
Download installer
  1. Run the installer. No administrator rights needed.
  2. The installer is not signed, so SmartScreen warns about it: click More info → Run anyway.

Linux beta Your system

x86_64 · glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 and newer) · SD-Sync-Immich-x86_64.AppImage
Download AppImage
  1. Make it executable and run it: chmod +x SD-Sync-Immich-x86_64.AppImage
  2. On GNOME the tray icon needs the AppIndicator extension (Ubuntu has it).

Checksums, command-line binaries and older versions are on the GitHub releases page. Full instructions are in the README.
