# sd-sync-immich

Приложение в menu bar macOS (и в трее Windows и Linux — бета): ждёт подключения выбранной SD-карты и загружает новые фото/видео в [Immich](https://immich.app).

**Требования:** macOS 13+ (Apple Silicon или Intel), Immich v3. Windows 10/11 (x64)
и Linux (x86_64) — бета, см. [Windows и Linux (бета)](#windows-и-linux-бета).

## Возможности

- Иконка в menu bar с текущим статусом и меню: открыть окно, синхронизировать
  сейчас/остановить, обновление, выход
- Окно приложения с разделами **Статус**, **Галерея**, **История**, **Карты** и
  **Настройки** (сервер Immich и журнал — в **Настройках**; в Dock появляется,
  только пока окно открыто)
- Интерфейс на 8 языках (см. [Языки](#языки))
- По умолчанию ничего не синхронизирует — только после выбора карты
- Автозапуск при входе в систему (LaunchAgent), включается и выключается в **Настройках**
- Автоматически находит фото и видео в стандартных каталогах камер
- Поддерживает распространённые фото, RAW и видеоформаты Immich
- Совместимость с **Immich v3** ([migration guide](https://immich.app/blog/v3-migration))
- Дедупликация: watermark по дате файла + заголовок `x-immich-checksum` (как в [immich-go](https://github.com/simulot/immich-go))
- Параллельная загрузка по HTTP/1.1, по умолчанию 4 соединения (настраивается в **Настройках**)
- Повтор загрузки при сбоях сети; если Immich недоступен, синхронизация останавливается с сохранением прогресса и продолжается, когда сервер снова доступен
- **Галерея**: фото со вставленной карты по дням, новые сверху, с отметкой
  статуса загрузки (в Immich / загружается / ждёт / ошибка) и просмотром на весь
  экран; видео и RAW в галерее не показываются, только считаются
- XMP-сайдкары (`IMG.JPG.xmp`, `IMG.xmp`) загружаются вместе с файлом
- Карту можно сразу вынимать: после загрузки она извлекается сама; по желанию —
  форматируется, когда всё с неё проверено в Immich (см. [Карта после загрузки](#карта-после-загрузки))
- Уведомления macOS: готово, ошибки, другая карта, проблемы с сервером, карта —
  каждый вид включается отдельно
- Автоматическая и ручная проверка обновлений через GitHub Releases

## Установка

Нужна macOS 13 или новее (Apple Silicon или Intel). Windows и Linux — в
разделе [Windows и Linux (бета)](#windows-и-linux-бета).

### Из GitHub Releases: DMG (рекомендуется)

1. Откройте [Releases](https://github.com/brofrong/sd-sync-iimich/releases/latest)
   и скачайте **`SD-Sync-Immich.dmg`**. Остальные файлы релиза для Mac —
   архив и бинарники для командной строки; двойным щелчком они не
   открываются как приложение.
2. Откройте DMG и перетащите **SD Sync Immich** на папку **Applications**
   в том же окне. Если у вас нет прав администратора, перетащите приложение
   в `~/Applications` (папка «Программы» в домашней папке).
3. Приложение подписано ad hoc, без Apple Developer ID, поэтому первый
   запуск macOS заблокирует. Откройте **Системные настройки →
   Конфиденциальность и безопасность**, внизу у сообщения о SD Sync Immich
   нажмите кнопку открытия и подтвердите. Или снимите карантин в Терминале:

   ```bash
   xattr -dr com.apple.quarantine /Applications/"SD Sync Immich.app"
   open /Applications/"SD Sync Immich.app"
   ```

4. Чтобы приложение запускалось при входе в систему, включите
   **Настройки → Автозапуск**.

Вместо DMG можно скачать **`SD-Sync-Immich.zip`**: распакуйте его и
перенесите приложение в папку «Программы».

### Из GitHub Releases: бинарник

Ассеты релиза:
- **`sd-sync-immich`** — universal binary (Apple Silicon + Intel)
- **`sd-sync-immich-darwin-arm64`** — только Apple Silicon
- **`sd-sync-immich-darwin-amd64`** — только Intel

```bash
chmod +x sd-sync-immich
./sd-sync-immich install
```

Команда `install`:
- собирает из бинарника `~/Applications/SD Sync Immich.app` и подписывает его ad hoc
- создаёт LaunchAgent `com.sd-sync-immich` (автозапуск при входе в систему) и сразу запускает приложение
- удаляет бинарник `~/Applications/sd-sync-immich`, если он остался от v0.3.0

Проверить checksum (опционально, в папке со скачанными файлами):

```bash
shasum -a 256 -c checksums.txt --ignore-missing
```

### Обновление с v0.3.0

Ничего делать не нужно: v0.3.0 скачает обновление как обычно, а новая версия
при первом запуске сама соберёт `~/Applications/SD Sync Immich.app`, перенастроит
LaunchAgent на него, удалит старый бинарник `~/Applications/sd-sync-immich` и
перезапустится уже из приложения. Настройки, выбранная карта и история
синхронизаций сохраняются.

### Сборка из исходников

Нужны [Go](https://go.dev/dl/) 1.26+, [Node.js](https://nodejs.org) 22+ и
Xcode Command Line Tools (`xcode-select --install`). Wails CLI запускается
через `go run`, отдельно ставить его не нужно.

```bash
git clone https://github.com/brofrong/sd-sync-iimich.git
cd sd-sync-iimich
scripts/build-app.sh dev dist
open dist   # SD Sync Immich.app, SD-Sync-Immich.zip и (с dmgbuild) SD-Sync-Immich.dmg
# или сразу установить с автозапуском:
dist/sd-sync-immich install
```

Только фронтенд и бинарник для разработки:

```bash
scripts/build-frontend.sh
CGO_ENABLED=1 go build -o sd-sync-immich ./cmd/sd-sync-immich
```

### Удаление

Удаляет приложение, LaunchAgent и бинарник v0.3.0 (настройки и история
остаются в `~/.config/sd-sync-immich`):

```bash
~/Applications/"SD Sync Immich.app"/Contents/MacOS/sd-sync-immich uninstall
```

Если приложение ставилось из DMG в `/Applications`, выполните команду из
него, а затем перетащите приложение в Корзину:

```bash
/Applications/"SD Sync Immich.app"/Contents/MacOS/sd-sync-immich uninstall
```

## Windows и Linux (бета)

Те же функции, что на Mac, но версии для Windows и Linux пока проверены меньше.
Если что-то работает не так — [сообщите об ошибке](#сообщить-об-ошибке).

### Windows

Нужна Windows 10 или 11 (x64); WebView2 в них уже есть.

1. Скачайте **`SD-Sync-Immich-Setup-x64.exe`** из
   [Releases](https://github.com/brofrong/sd-sync-iimich/releases/latest) и
   запустите. Права администратора не нужны: приложение ставится для текущего
   пользователя в `%LOCALAPPDATA%\Programs\SD Sync Immich`, ярлык — в меню
   «Пуск».
2. Установщик не подписан (сертификат подписи кода платный), поэтому Windows
   SmartScreen покажет «Система Windows защитила ваш компьютер». Нажмите
   **Подробнее → Выполнить в любом случае**. Браузер Edge может ещё при
   скачивании предупредить, что файл «скачивают нечасто»: наведите на файл в
   списке загрузок → **…** → **Сохранить** (в следующем вопросе —
   **Показать больше → Все равно сохранить**).
3. Установщик включает автозапуск при входе в систему; выключить его можно в
   **Настройки → Автозапуск** (обновления этот выбор сохраняют).

Приложение живёт в трее (область уведомлений справа на панели задач; значок
может быть спрятан под стрелкой «^»). Закрытие окна прячет его в трей, окно
снова открывается кликом по значку; **Выход** — в меню значка.

Обновление: приложение скачивает новый установщик, проверяет SHA-256 из
`checksums.txt`, запускает его в тихом режиме и закрывается; установщик
заменяет программу и снова запускает её.

Удаление: **Параметры → Приложения → SD Sync Immich → Удалить**. Удаляются
программа, ярлык и автозапуск; настройки, история и логи остаются.

### Linux

Нужен Linux x86_64 с glibc 2.35 или новее (Ubuntu 22.04+, Debian 12+,
Fedora 36+ и ровесники), графическим рабочим столом (GNOME, KDE и т.п.) и
сессионной шиной D-Bus — она есть в любом обычном сеансе рабочего стола
(через неё работают трей, уведомления, извлечение и форматирование карты).

1. Скачайте **`SD-Sync-Immich-x86_64.AppImage`** из
   [Releases](https://github.com/brofrong/sd-sync-iimich/releases/latest),
   положите туда, где он будет жить (например, `~/Applications`), сделайте
   исполняемым и запустите:

   ```bash
   chmod +x SD-Sync-Immich-x86_64.AppImage
   ./SD-Sync-Immich-x86_64.AppImage
   ```

   Если AppImage не запускается с ошибкой про FUSE, установите пакет `fuse3`
   (в некоторых дистрибутивах он называется `fuse`).
2. Автозапуск включается в **Настройки → Автозапуск** (создаёт
   `~/.config/autostart/sd-sync-immich.desktop`). Он запускает AppImage по
   текущему пути: если переместите файл, выключите и снова включите
   автозапуск.

**GNOME:** значков в трее в GNOME нет без расширения
[AppIndicator and KStatusNotifierItem Support](https://extensions.gnome.org/extension/615/appindicator-support/)
(в Ubuntu оно уже включено). Без трея приложение тоже работает: закрытие окна
сворачивает его в панель задач (док), синхронизация продолжается. KDE и
большинство других окружений трей показывают сами.

Карта должна монтироваться рабочим столом как обычно (`/media/<user>/…` или
`/run/media/<user>/…`); извлечение и форматирование — через UDisks2, как
кнопка «Извлечь» в файловом менеджере, без root.

Обновление: приложение скачивает новый AppImage, проверяет SHA-256 из
`checksums.txt`, заменяет им свой файл и перезапускается (для этого папка с
AppImage должна быть доступна на запись). Запущенное не из AppImage
приложение только сообщает о новой версии.

Удаление: удалите AppImage и, если включали автозапуск, файл
`~/.config/autostart/sd-sync-immich.desktop`.

### Где данные и логи

| | Настройки и история (`config.yaml`, база) | Логи (`app.log`) |
|---|---|---|
| Windows | `%APPDATA%\sd-sync-immich` | `%LOCALAPPDATA%\sd-sync-immich\logs` |
| Linux | `~/.config/sd-sync-immich` | `~/.local/state/sd-sync-immich` |
| macOS | `~/.config/sd-sync-immich` | `~/Library/Logs/sd-sync-immich` |

Лог виден и в окне: **Настройки** → **Открыть журнал**. Удаление программы эти папки не
трогает.

### Форматирование карты

Правила те же, что на Mac (см. [Карта после загрузки](#карта-после-загрузки)),
но приложение никогда не запрашивает права администратора. На Windows
форматирование тома требует прав администратора, поэтому без запуска от имени
администратора приложение карту не форматирует: сразу после загрузки (без
проверки и 30-секундного отсчёта) оно сообщает «Не удалось отформатировать» с
пояснением, что нужны права администратора, и извлекает карту, если включено
извлечение, — отформатируйте карту в камере. Под переключателем
форматирования в настройках это тоже написано. На Linux форматирование
заканчивается тем же сообщением, если система требует для него пароль
(polkit). После такого сообщения приложение до извлечения карты больше не
пытается её форматировать.

Карты в FAT16 (обычно 2 ГБ и меньше) на Windows и Linux не форматируются
автоматически (на Mac — форматируются): приложение сообщает «Не удалось
отформатировать», карта остаётся как была.

### Сообщить об ошибке

Создайте [issue](https://github.com/brofrong/sd-sync-iimich/issues/new):
система и её версия (для Linux — дистрибутив и рабочий стол), что делали, что
ожидали и что произошло; приложите `app.log` (см. [Где данные и логи](#где-данные-и-логи)),
убрав из него то, чем не хотите делиться.

## Первый запуск

1. Откройте приложение (или дождитесь автозапуска после `install`); окно
   открывается из меню в menu bar → **Открыть SD Sync Immich** (на Windows и
   Linux — кликом по значку в трее)
2. **Настройки** → **Сервер**: укажите **Immich URL** (например `https://immich.example.com`)
   и **API Key** (Immich → Settings → API Keys), нажмите **Проверить подключение** и **Сохранить**
3. Вставьте SD-карту → раздел **Карты** → **Выбрать**
4. При подключении карты синхронизация запустится автоматически

Опция **Настройки → Искать папки камер автоматически** включена по умолчанию. Она
добавляет к пользовательским путям известные структуры носителей:

- `DCIM/` — Canon, Nikon, Fujifilm, Olympus, GoPro, DJI и другие DCF-камеры
- `PRIVATE/M4ROOT/CLIP/` — Sony XAVC S
- `PRIVATE/AVCHD/BDMV/STREAM/` — Sony, Panasonic и Canon AVCHD
- `MP_ROOT/` — старые режимы Sony MP4
- `PRIVATE/XDROOT/Clip/` и `XDROOT/Clip/` — профессиональные камеры Sony

Автопоиск включает форматы, поддерживаемые Immich: распространённые изображения,
RAW (`ARW`, `CR2/CR3`, `NEF`, `RAF`, `RW2`, `ORF`, `DNG` и другие) и видео
(`MP4`, `MOV`, `MTS/M2TS`, `MXF` и другие). При отключении используются только
`scan.paths` и `scan.extensions` из конфигурации.

Конфиг: `~/.config/sd-sync-immich/config.yaml` (пример: [`config.example.yaml`](config.example.yaml))  
Логи: `~/Library/Logs/sd-sync-immich/app.log` (в окне: **Настройки** → **Открыть журнал**)  
Windows и Linux — см. [Где данные и логи](#где-данные-и-логи).

## Карта после загрузки

**Настройки → Карта**:

- **Извлекать карту после загрузки** (включено по умолчанию). Когда синхронизация
  загрузила файлы без ошибок, карта извлекается — её можно вынимать. После
  «нечего загружать», ошибок или остановки карта остаётся подключённой —
  кроме случая, когда включено форматирование: отформатированная карта
  извлекается и после «нечего загружать».
- **Форматировать карту после загрузки** (выключено по умолчанию; при включении
  приложение переспрашивает). После синхронизации без ошибок приложение обходит
  всю карту и проверяет, что каждое фото и видео есть в Immich, затем 30 секунд
  ждёт (в окне и в уведомлении есть **Отменить**) и форматирует карту в тот же
  формат (exFAT/FAT32) с тем же именем. Если хоть один файл не найден в Immich
  или на карте есть фото/видео форматов, которые не загружаются, карта не
  форматируется, а приложение пишет почему.

> **Внимание:** форматирование удаляет **все** файлы с карты, включая то, что не
> является фото и видео. Файлы, лежащие в корзине Immich, **не считаются
> загруженными**: если фото удалено в Immich и ещё лежит в корзине, карта не
> будет отформатирована. Если камера после форматирования попросит восстановить
> базу, отформатируйте карту в самой камере.

Файлы, которые не загрузились, видны в **Истории**: строку синхронизации с
ошибками можно раскрыть (путь, вид ошибки, подробности) и нажать **Повторить
ошибки** — для этого карта этой синхронизации должна быть выбрана и вставлена.

### Уведомления

**Настройки → Уведомления**: общий выключатель и пять видов — «Готово», «Готово
с ошибками», «Вставлена другая карта», «Проблемы с сервером» и «Карта:
форматирование и извлечение». Каждого вида приходит не больше одного уведомления
на одну вставку карты. Кнопки в уведомлениях (**Подробнее**, **Выбрать эту
карту**, **Повторить**, **Настройки сервера** — если ключ API отклонён,
**Отменить**) есть, когда приложение запущено из
`SD Sync Immich.app`; иначе уведомления показываются без кнопок. На Windows и
Linux кнопки есть там, где система их показывает; клик по уведомлению
открывает окно.

## Языки

Интерфейс переведён на английский, русский, немецкий, испанский, французский,
португальский (Бразилия), китайский (упрощённый) и японский. По умолчанию
используется язык системы (первый поддерживаемый из списка языков macOS; на
Windows — язык интерфейса Windows, на Linux — `LANG`/`LC_*`; иначе
английский); выбрать другой можно в **Настройки → Язык**, интерфейс
переключается сразу.

## Команды

Бинарник — `~/Applications/SD Sync Immich.app/Contents/MacOS/sd-sync-immich`
(или скачанный `sd-sync-immich`). На Windows и Linux есть только `run` (он же
запуск без аргументов) и `scan-test`. На Windows программа собрана без окна
консоли, поэтому вывод `scan-test` виден только через конвейер, например
`& "$env:LOCALAPPDATA\Programs\SD Sync Immich\sd-sync-immich.exe" scan-test E:\ | more`
в PowerShell.

| Команда | Описание |
|---------|----------|
| `run` | Запуск с иконкой в menu bar |
| `install` | Установить `SD Sync Immich.app` в `~/Applications` с автозапуском |
| `uninstall` | Удалить приложение и автозапуск |
| `scan-test [mount]` | Проверить сканирование (по умолчанию `/Volumes/Brofrong`) |

## Обновления

Релизная версия проверяет обновления при запуске и затем каждые 12 часов.
Ручная проверка — **Настройки → Проверить обновления**. При обнаружении
новой версии приложение показывает release notes и запрашивает
подтверждение. Перед атомарной заменой исполняемого файла в приложении
проверяется SHA-256 из `checksums.txt`, затем приложение заново
подписывается и перезапускается. Как обновляются Windows и Linux — в разделе
[Windows и Linux (бета)](#windows-и-linux-бета).

**Выход** из меню завершает приложение до следующего входа в систему (или
до ручного запуска).

Локальная сборка с версией `dev` не обновляется автоматически.

## API Key

Создайте в Immich: **Settings → API Keys → Create** с правом `upload`.

## Релизы

Project skill `.cursor/skills/release` анализирует изменения после последнего
тега, предлагает `major`, `minor` или `patch` и показывает release notes.
После подтверждения он запускает:

```bash
scripts/release.sh <major|minor|patch>
```

Скрипт требует чистую ветку `main`, совпадающую с `origin/main`, вычисляет
следующую SemVer-версию и после отдельного подтверждения отправляет новый тег.
При push тега `v*` GitHub Actions собирает macOS, Windows и Linux и публикует
один релиз со всеми файлами и общим `checksums.txt`. Ручной запуск release
workflow — пробная сборка: те же файлы появляются как артефакты запуска,
релиз не публикуется (только на теге `v*` с отмеченным `publish`):

```bash
gh workflow run release.yml --ref <ветка>
```

Релиз публикуется, только когда собрались все три системы. Если сборка одной
из них упала (например, сбой сети), откройте запуск тега в Actions и нажмите
**Re-run failed jobs**: пересоберутся упавшие задания, и релиз опубликуется.

Сборка локально: macOS — `scripts/build-app.sh <версия> dist`; Linux —
`scripts/build-linux.sh <версия> dist` (на Mac — в Docker, AppImage под
архитектуру машины, `BUILD_ARCH=amd64` — x86_64; папка для результата — внутри
репозитория, контейнер получает только его); Windows — на Windows
`scripts/build-windows.ps1 -Version <версия> -OutDir dist` (нужен NSIS).
